About the Project

Sound of Wind is an interactive sound installation that transforms environmental data into an immersive auditory experience. The project bridges the gap between meteorological data and artistic expression by converting Hong Kong's wind patterns into a dynamic sound installation.

This installation creates a unique dialogue between natural phenomena and digital sound, allowing visitors to experience wind data through an artistic interpretation of sound and movement. The project demonstrates how environmental data can be transformed into meaningful artistic expressions, creating a new perspective on our relationship with natural phenomena.

Technical Details

Data Collection & Processing

Wind Speed Data Analysis from Hong Kong Observatory

Data Processing Workflow

  • Source: Hong Kong Observatory wind speed data (one year period)
  • Data Processing: Excel-based cleaning and normalization
  • Value Mapping: Wind speed conversion from 0-80 km/h to 0-255 scale
  • Visualization: Line chart plotting for data analysis

Sound Processing System

Sound Processing System in MaxMSP

MaxMSP Implementation

  • Real-time sound generation and processing
  • Multiple audio layers controlled by wind data
  • Dynamic sound modulation based on wind patterns
  • Data-driven audio parameter mapping

Hardware Control

Arduino Control System

Arduino Implementation

  • Four motor control pins (5, 6, 12, 13)
  • Two speed control pins (9, 10)
  • Wind speed data mapping (0-80 km/h to 0-255)
  • Real-time fan speed adjustment based on data input
