# Sound of Wind Installation

An interactive sound installation that transforms Hong Kong Observatory wind data into an immersive auditory experience.

## Project Overview

This installation creates a unique dialogue between natural phenomena and digital sound, allowing visitors to experience wind data through an artistic interpretation of sound and movement. The project demonstrates how environmental data can be transformed into meaningful artistic expressions.

## Technical Implementation

- Data source: Hong Kong Observatory wind speed data
- Hardware: Arduino-controlled fan system
- Sound Processing: MaxMSP
- Data Processing: Excel-based cleaning and normalization

## Setup

1. Clone this repository
2. Open `index.html` in a modern web browser
3. No additional dependencies required
